# Architecture

**Hexagonal architecture (ports and adapters)** in a single local Python process: a NiceGUI web UI on `127.0.0.1:8731` ([ADR-010](adr/ADR-010-nicegui-ui-as-built.md)), services on the asyncio loop, and adapters for LLM providers, persistence, artifact storage, sandbox and secrets wired by one composition root, `AppContext` ([ADR-011](adr/ADR-011-ports-and-adapters-as-built.md)).

                                      │ ──────────────────────────────────────────────────────────│

Everything runs on the user's machine. External traffic is limited to the LLM providers, Firestore and Firebase Storage (when enabled) and Docker Hub / MCR for the first image pull. Generated code only runs in the sandbox ([P4](../00-overview/constitution.md)).

## Package structure (as built)

```
src/aidriven/
├── __main__.py          # python -m aidriven  → app.run()   (console script: aidriven)
├── app.py               # builds AppContext, logging, bootstrap, registers pages, ui.run()
├── config.py            # EnvSettings (AIDRIVEN_*), AppConfig (+ Firestore/Storage/Judge/Sandbox configs), ConfigStore
├── context.py           # AppContext: composition root + Settings actions (Firestore, storage, backup, adapters)
├── logging_setup.py     # rotating file + in-memory LogCapture (Firestore index-URL hints)
├── ports.py             # LLM dataclasses (Message, ToolCall, LLMRequest, LLMResponse...), LLMError, Protocols
├── domain/models.py     # pydantic entities, enums, Score.final, Pricing.cost, validate_params, ENTITY_TYPES
├── adapters/
│   ├── llm/             # base (retries, Stopwatch, refusal heuristic), catalog, anthropic_adapter,
│   │                    # openai_adapter (OpenAIResponsesAdapter, ChatCompletionsAdapter), gemini_adapter,
│   │                    # ollama_adapter, fake_adapter; __init__.build_adapter()
│   ├── repo_sqlite.py   # SqliteRepository
│   ├── repo_firestore.py# FirestoreRepository, init_firestore_app
│   ├── artifact_stores.py # LocalArtifactStore, FirebaseStorageArtifactStore, safe_name
│   ├── sandbox.py       # DockerSandbox, ProcessSandbox, SandboxManager
│   └── secrets.py       # KeyringSecretStore, MemorySecretStore, EncryptedRepoSecretStore, derive_fernet_key, resolve_api_key, mask
├── services/            # runner, agent, checks, scoring, judge, comparison, artifacts, prompting, task_io, bootstrap
├── sandbox_harness/     # aidriven_harness.py (stdlib only, copied into every sandbox job)
├── seed/                # tasks/*.yaml + assets/ (generated by tools/gen_seed_assets.py)
└── ui/                  # common (frame, dialogs, iframe), i18n, charts, pages/*.py, locales/{en,es}.json
tests/  unit/*.py · fixtures/seed_solutions/<slug>/ (reference solutions, also served by the fake "oracle")
tools/  gen_seed_assets.py (deterministic seed asset generator)
```

Dependency rule (reviewed, not linted): `domain` imports nothing from the project; `ports` imports only `domain`; `adapters` import `ports`, `domain`, `config`; `services` import `ports`, `domain` and SDK-free adapter helpers (`BaseAdapter` type, `looks_like_refusal`, `catalog`, `safe_name`); `context.py` wires everything; `ui` uses `AppContext`, services and helpers.

## Run flow (end to end)

1. The user creates a **suite** in *Batteries* ([battery.md](../03-modules/battery.md)) or selects tasks for a **quick run** in *Tasks* ([tasks.md](../03-modules/tasks.md)).
2. `RunnerService.create_run` (or `create_from_suite` / `create_rerun`) loads the entities, freezes a `RunSnapshot`, creates the `Run` and one `Result` per item; items whose model lacks a required capability are created as `skipped` ([execution.md](../03-modules/execution.md)).
3. `RunnerService.start` launches an asyncio task; items run under `asyncio.Semaphore(run.concurrency)`. For each item `process()` validates params, builds the request (`prompting.build_request`: system prompt from rulesets + agent persona + profile prompt; user message with documents, images and delivery instructions), calls the adapter (or `AgentRunner` when the run has an agent and the model supports tools) under `asyncio.wait_for(task_timeout_s)` and records `Metrics`.
4. `services.artifacts.extract_files` pulls files from the response (```` ```<lang> file=<name> ```` plus fallbacks); they are stored through the artifact store selected by the cloud toggle ([artifacts-sandbox.md](../03-modules/artifacts-sandbox.md)).
5. `CheckEngine.run_all` executes the task's checks — simple kinds in-process, code kinds in the sandbox with the harness — and `scoring.auto_score` computes `Score.auto`.
6. If the run has a judge, `JudgeService` produces a blind `JudgeVerdict` → `Score.judge` ([evaluation.md](../03-modules/evaluation.md)).
7. The run page polls progress; in *Review* or on the result page the user sets or accepts the score; *Compare* aggregates the four dimensions ([comparison.md](../03-modules/comparison.md)).

## Persistence and configuration selection

At startup `AppContext` reads `data/config.json` (`AppConfig`). The repository is `SqliteRepository(data/aidriven.db)` unless `firestore.enabled` is true, in which case `FirestoreRepository` is activated (falling back to SQLite with an ERROR log if that fails). New artifacts go to the Firebase store when `storage.cloud_enabled` is true, else to `data/artifacts/`. See [persistence-firestore.md](../03-modules/persistence-firestore.md) and [ADR-012](adr/ADR-012-sqlite-firestore-and-local-config.md).
