## Environment variables (startup values / fallbacks)

`EnvSettings` reads these (and a `.env` file; see `.env.example`):

```
AIDRIVEN_DATA_DIR=data            # SQLite, artifacts, secrets, logs, config.json, backups
AIDRIVEN_HOST=127.0.0.1           # bind address; local only by default
AIDRIVEN_PORT=8731
AIDRIVEN_RELOAD=false             # NiceGUI auto-reload (development)
AIDRIVEN_STORAGE_SECRET=...       # signs NiceGUI per-browser storage (UI language, theme)
AIDRIVEN_ENCRYPTION_KEY=          # optional: material for the key that encrypts API keys in Firestore
                                  # (default: the uploaded service account's private_key)
# API key fallbacks when no key is saved for a connection (read-only):
ANTHROPIC_API_KEY=  OPENAI_API_KEY=  AZURE_OPENAI_API_KEY=  GEMINI_API_KEY=
OPENROUTER_API_KEY=  OLLAMA_API_KEY=  OPENAI_COMPATIBLE_API_KEY=
```

There are no command-line flags and no log-level variable (the log level is INFO). Everything else is configured from the UI ([P9](../00-overview/constitution.md)).

## Cost and limit guardrails

- **Provider rate limits**: transient errors (408/409/425/429/5xx, connection/timeout errors) are retried by `BaseAdapter` with backoff `min(2·2^n + U(0,1), 30)` seconds, up to `ProviderConnection.max_retries` (default 2); SDK-internal retries are disabled (`max_retries=0`). `Retry-After` is not read. The retry count is stored in `Metrics.retries`.
- **Cost visibility**: `Pricing` per profile (pre-filled from the catalog or OpenRouter discovery); every result shows its cost and every run/series its total. The suite editor shows the number of executions (`tasks × models × repetitions`), not a cost estimate.
- **Firestore writes**: a result is written when it starts and when it finishes (plus once at creation in a batch); the run document is written after every finished item.
- **Docker**: one container per job, force-removed afterwards; images are pulled once on first use.
